|---|---|

| **Module** | Code Verification |

| **Date reported** | October 2026 |

## Steps to reproduce
1. Open the verification page (code option)
2. Enter a valid code in lowercase and click Verify
3. Enter the same code in uppercase and click Verify

## Test data
Same code in lowercase and uppercase

## Expected result
Behaviour should be consistent (same result, or a clear message).

## Actual result
Behaviour is not consistent.
